# Contributing

Bug reports and pull requests are welcome.

Before opening a pull request:

1. Run `python scripts/validate_repo.py`.
2. Check both Indonesian and English README files when changing deployment behavior.
3. Never include real Railway variables, passwords, browser cookies, profile files, or downloads.
4. Explain any change to the base image, authentication, port, or persistent volume.

By submitting a contribution, you agree that your contribution is provided under the repository's MIT license.

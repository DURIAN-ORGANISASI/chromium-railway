# Contributing

Bug reports and pull requests are welcome.

Before opening a pull request:

1. Run `python scripts/validate_repo.py`.
2. Check both Indonesian and English README files when changing deployment behavior.
3. Never include real Railway variables, passwords, browser cookies, profile files, or downloads.
4. Explain any change to the base image, authentication, port, startup wrapper, or persistent volume.
5. Keep the attribution and license notices in `NOTICE.md` and `LICENSES/` intact when modifying GPL-covered files.

Original documentation and artwork remain under MIT. The Dockerfile integration and compatibility code under `services/browser/` are GPL-3.0-or-later.
